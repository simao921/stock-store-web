# 💎 Stock Store Web - Soberania Digital

Uma plataforma de e-commerce premium desenvolvida com **React**, **Vite** e **Tailwind CSS**, integrada com **Supabase** para gestão de inventário e **Discord** para notificações em tempo real.

## 🚀 Tecnologias
- **Frontend**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Framer Motion (animações premium)
- **Database**: Supabase
- **Notificações**: Discord Webhooks
- **Gráficos**: Recharts

## 🛠️ Configuração Local
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Configure o seu ficheiro `.env` com as credenciais do Supabase.
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 📦 Deploy (Vercel)
O projeto está pronto para ser enviado para o Vercel. Certifique-se de configurar as variáveis de ambiente no dashboard do Vercel para que a integração com o Supabase e Discord funcione corretamente.
